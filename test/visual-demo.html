1. Comet Trail — particle stream with head glow

A bright leading orb followed by a stream of fading particles. Longer prompts = more particles. Color = prompt (cyan) vs response (orange).

2. Lightning Arc — branching energy discharge

A jagged bolt that fires from source to target, with afterglow segments that fade independently. Fast, dramatic, cheap (just lines).

3. DNA Helix — dual intertwined particle streams

Two sinusoidal streams spiraling around the path, with cross-links. Prompt sends one color pair, response sends another.

4. Pulse Wave — expanding rings along the path

Concentric rings spawn at the source and travel along the curve, expanding and fading. Like sonar pings flowing through space.

5. Firefly Swarm — scattered particles drifting along path

A loose cloud of tiny glowing dots that drift along the curve with slight random wobble. Organic, ambient feel. Each dot has its own speed/offset.
